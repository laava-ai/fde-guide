# Laava FDE Guide

A forward deployed engineer works alongside the people who use a system. Their job includes finding the right problem, building a change that fits the workflow, and helping the team run it after delivery.

This field guide follows a service desk that wants help routing incoming requests. You can complete the exercise with Python 3.10 or later and a text editor. All examples use fictional requests.
